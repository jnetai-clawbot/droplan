# Changelog

## v1.0.0 - Initial Release

- Local network device discovery via UDP multicast
- TCP file transfer (send and receive)
- Clipboard sync between paired devices
- QR code pairing support
- Dark Material Design 3 theme with cyan/teal neon accents
- Room database for transfer history and known devices
- Settings screen with version info, share, and check for updates
- "Made By jnetaol.com" branding
- Debug logger with DL-xxx error codes
- ARM64-only builds
- GitHub Actions CI/CD (debug on push, signed release on tag/manual)
